This is a small web game I made for the **Magical Mirai Programming Contest 2026**. This is also my first project that spans months long, as I am starting to focus more on bigger projects than just game jams.

Though, for this project, I didn't really have a schedule or timetable or anything. So everything was spontaneously done and a lot of last-minute sessions.

Anyway, this web app has to involve the usage of the **TextAlive App API**, a Javascript API that provides the timing of lyrics to many songs, notably [Vocaloid songs](https://www.google.com/search?q=vocaloid+songs&rlz=1CDGOYI_enMY1150MY1150&oq=vocaloid+songs&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTINCAEQABiRAhiABBiKBTIHCAIQABiABDIHCAMQABiABDIHCAQQABiABDIHCAUQABiABDIQCAYQABiRAhiABBiKBRi0BzINCAcQABiRAhiABBiKBTINCAgQABiRAhiABBiKBTIHCAkQABiABNIBCDI0MjNqMWo3qAIasAIB4gMEGAEgX_EFrr8gI_D6GjTxBa6_ICPw-ho08QWuvyAj8PoaNA&hl=en-GB&sourceid=chrome-mobile&ie=UTF-8#sbfbu=1&pi=vocaloid%20songs). You can learn more about the API [here](https://github.com/TextAliveJp/textalive-app-api/blob/main/README.en.md). And because I didn't know anything about this API, I had to learn it in a short time, fast. Luckily for me, I managed to adapt quick and make the most basic application out, then only I expanded more.

For this game, I focused again on mixing the bullet hell and rhythm game genre, and I've done quite a lot on this so it should be right in my alley. I thought about having the lyrics as bullets, and the player, playing as Hatsune Miku, would "dance with them" (dodge them). The most prominent mechanic in the game is the different combinations of bullet patterns and lyric timings, which made charting the songs way different and actually more fun (You have to listen to the vibe of the section of the music and choose the best combination for it). Sometimes, it might lead to unexpected and amazing results.

Another thing is, it's actually my first time doing localization, so that's a plus.

If you want to try out the game. This is the [website](https://blulow.github.io/adanceonthelake/)!
