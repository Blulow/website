This is my first game jam with a team, submitted to a local game jam in my university club, **Bit Game Jam**.

It was almost all of the team members' first game jam, while for me it's being in a team. But surprisingly it didn't went as bad, as we are cooperative.

We used Unity, which was not my home game engine, but my skills transferred really well, and ended up programming most of the game. I used Unity before, though that was like 5 years ago, so I might still have some memory for it.

At first I was afraid what we should be doing and how to work as a team. But a whole new side of me just arised – my leadership instincts. And honestly I thought I would do really really bad. But in the end we did make a viable final product.

I still call myself just game director at most, not really a leader, maybe it's just modesty. But I was really proud of myself, haha.

Play it [here](https://blulow.itch.io/happy-little-explosions)!
