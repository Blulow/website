This is a small 3D modeling software that I am currently making using C++ and OpenGL. The modeling software would be focusing on blocky and low-poly styled models, but instead of using tons of voxels or fixed 3D shapes in a fixed limited grid to build it, I want to be able to use even a single cube, and carve it into the desired model, which can be done by vertex editing.

This will be quite a journey to take, so I wanted to log my progress and stuff I learned down into a series of devlogs. Even if it won't come out as great, I'm glad I have made something like this out.
